## 一、防抖(debounce)与节流(throttle)

| | 防抖 debounce | 节流 throttle |
|---|---------------|---------------|
| 语义 | **停 n 秒**才执行 | **每 n 秒最多**执行一次 |
| 场景 | 搜索输入、窗口 resize | 滚动、按钮连点、上报 |

```js
// 防抖
function debounce(fn, delay) {
  let t;
  return (...args) => { clearTimeout(t); t = setTimeout(() => fn(...args), delay); };
}

// 节流
function throttle(fn, interval) {
  let last = 0;
  return (...args) => {
    const now = Date.now();
    if (now - last >= interval) { last = now; fn(...args); }
  };
}
```

> 记忆:防抖"**等你消停**",节流"**限频**"。搜输入用防抖,滚动监听用节流。

## 二、内存泄漏与排查(原理见 2.6)

**常见泄漏源:** 全局变量 / 闭包长期持有大对象 / 未清理的定时器与监听器 / 游离 DOM 引用。

```js
// 反面:组件卸载未清理
useEffect(() => {
  const t = setInterval(() => {}, 1000);
  return () => clearInterval(t);   // ✅ 必须清理
}, []);
```

**排查:** DevTools → Memory → Heap Snapshot 前后对比,看对象数量异常增长。

## 三、缓存与引用优化

- 用 `WeakMap` 做"可自动回收"的缓存(强 Map 会撑爆)
- 大数据避免深拷贝副本,尽量复用/转移

## 小结

```
防抖:停 n 秒执行(搜索);节流:限频(滚动)
内存泄漏:定时器/监听器/闭包/全局 → 卸载时清理
排查:Heap Snapshot 对比
```

## 面试题

**Q1:手写防抖 + 立即执行版?**

```js
function debounce(fn, delay, immediate = false) {
  let t;
  return (...args) => {
    const call = () => fn.apply(this, args);
    if (immediate && !t) call();          // 首次立即
    clearTimeout(t);
    t = setTimeout(() => { t = null; if (!immediate) call(); }, delay);
  };
}
```

**Q2:哪些常见的内存泄漏场景?如何避免?**

① `setInterval`/`addEventListener` 用后不清理 → 在卸载钩子清理;② 闭包长期持有大对象 → 用完置 `null`;③ 全局变量堆积 → 避免误挂 `window`;④ `Map` 缓存无限增长 → 换 `WeakMap`/LRU。
