# A3 手写防抖 / 节流 / 柯里化

> 附录 A · 手写系列
> 思路:防抖"等你消停",节流"限频",柯里化"固定参数"——都是闭包 + 定时器。

---

## 一、防抖 debounce(停 n 秒才执行)

```js
function debounce(fn, delay = 300) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);                              // 每次触发都重置
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

**立即执行版(第一次立刻触发,之后防抖):**

```js
function debounce(fn, delay, immediate = false) {
  let timer = null;
  return function (...args) {
    const callNow = immediate && !timer;              // 首次立即
    clearTimeout(timer);
    timer = setTimeout(() => { timer = null; if (!immediate) fn.apply(this, args); }, delay);
    if (callNow) fn.apply(this, args);
  };
}
```

> 场景:搜索输入、窗口 resize、按钮防重复提交。

---

## 二、节流 throttle(每 n 秒最多一次)

```js
// 时间戳版:立即执行第一次
function throttle(fn, interval = 300) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) { last = now; fn.apply(this, args); }
  };
}

// 定时器版:延迟执行,保证最后一次也执行
function throttle(fn, interval = 300) {
  let timer = null;
  return function (...args) {
    if (timer) return;
    timer = setTimeout(() => { timer = null; fn.apply(this, args); }, interval);
  };
}
```

> 场景:滚动监听、鼠标移动、高频点击上报。

**区别**:时间戳版"首触发立即、尾触发可能丢";定时器版"首触发延迟、尾触发保留"。

## 三、柯里化 curry(固定部分参数)

```js
function curry(fn) {
  return function curried(...args) {
    if (args.length >= fn.length) return fn(...args);   // 参数够了,执行
    return (...rest) => curried(...args, ...rest);      // 不够,继续收集
  };
}

function add(a, b, c) { return a + b + c; }
const add1 = curry(add)(1);
console.log(add1(2)(3));    // 6
```

> 本质:`fn.length` 拿到形参个数,参数不够就返回"继续收集"的新函数。

---

## 四、易错点

1. **防抖忘 clearTimeout**:定时器累积,逻辑错乱
2. **节流时间戳 vs 定时器**:首尾触发的语义不同,按场景选
3. **this 丢失**:回调里 `fn.apply(this, args)` 保住 this,别直接 `fn(...args)`
4. **柯里化形参个数**:`fn.length` 只算"默认值之前的参数个数",有默认值时需手动指定

---

## 五、自测

```js
const d = debounce((x) => console.log("d", x), 200);
d(1); d(2); d(3);              // 只打印 "d 3"

const t = throttle((x) => console.log("t", x), 200);
t(1); t(2); t(3);              // 只打印 "t 1"(时间戳版)
```
