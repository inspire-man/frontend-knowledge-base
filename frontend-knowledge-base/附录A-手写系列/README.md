## 手写题的通法

手写题考的是**对底层机制的理解**,不是背代码。每篇按「思路 → 完整实现 → 易错点」展开,重点看**思路与边界**,而非死记。

- **Promise**:状态机 + 回调队列 + 链式穿透
- **call/apply/bind**:改变 this + 参数处理(bind 还要柯里化 + 兼容 new)
- **深拷贝**:递归 + WeakMap 处理循环引用 + 类型判断
- **防抖节流**:闭包 + 定时器(时间戳 vs 定时器)
- **发布订阅**:一个事件中心,on/emit/off/once
