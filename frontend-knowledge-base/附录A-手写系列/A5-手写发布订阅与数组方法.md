# A5 手写发布订阅 / 数组常用方法

> 附录 A · 手写系列
> 思路:发布订阅 = 一个事件中心(on 注册 / emit 触发 / off 移除);数组方法 = 回调 + 遍历。

## 一、发布订阅 EventEmitter

```js
class EventEmitter {
  constructor() { this.events = {}; }               // { eventName: [fn, ...] }

  on(name, fn) {
    (this.events[name] ||= []).push(fn);
    return this;                                    // 链式
  }

  once(name, fn) {
    const wrapper = (...args) => { fn(...args); this.off(name, wrapper); };
    wrapper.fn = fn;                                // 保留原函数,供 off 精确移除
    return this.on(name, wrapper);
  }

  emit(name, ...args) {
    (this.events[name] || []).forEach((fn) => fn(...args));
  }

  off(name, fn) {
    if (!fn) delete this.events[name];
    else this.events[name] = (this.events[name] || []).filter((f) => f !== fn && f.fn !== fn);
    return this;
  }
}
```

**面试要点:**

- `once` 用"包装函数"实现:执行一次后 `off` 自己,并保留 `wrapper.fn` 指向原函数供精确移除
- `off` 支持"移除某个"和"移除全部"
- 这是 **Vue 的 `$on/$emit/$off`、EventBus、Node 的 EventEmitter** 的底层模型

## 二、数组常用方法(map/filter/reduce/flat/去重)

```js
// map:遍历并返回新数组
Array.prototype.myMap = function (fn) {
  const res = [];
  for (let i = 0; i < this.length; i++) res.push(fn(this[i], i, this));
  return res;
};

// filter:保留满足条件的
Array.prototype.myFilter = function (fn) {
  const res = [];
  for (let i = 0; i < this.length; i++) if (fn(this[i], i, this)) res.push(this[i]);
  return res;
};

// reduce:累积
Array.prototype.myReduce = function (fn, init) {
  let acc = init === undefined ? this[0] : init;
  let i = init === undefined ? 1 : 0;
  for (; i < this.length; i++) acc = fn(acc, this[i], i, this);
  return acc;
};

// flat:拍平(递归版)
Array.prototype.myFlat = function (depth = 1) {
  return depth > 0
    ? this.reduce((acc, v) => acc.concat(Array.isArray(v) ? v.myFlat(depth - 1) : v), [])
    : this.slice();
};

// 去重(三种)
const dedupe1 = (arr) => [...new Set(arr)];                       // Set,最简洁
const dedupe2 = (arr) => arr.filter((v, i) => arr.indexOf(v) === i);  // indexOf
const dedupe3 = (arr) => [...arr.reduce((m, v) => m.set(v, 1), new Map()).keys()]; // Map
```

---

## 三、易错点

1. **reduce 无 init**:初始值应是第一个元素、从下标 1 开始遍历;空数组无 init 会报错
2. **map/filter 返回新数组**:别在原数组上改(有副作用)
3. **flat 递归深度**:`depth > 0` 才继续,`depth=1` 拍一层
4. **去重 Set 法**:只适合"原始值 + 同引用";对象数组去重需按字段(用 Map key)

## 四、自测

```js
const ee = new EventEmitter();
const log = (x) => console.log("触发", x);
ee.once("a", log);
ee.emit("a", 1);   // 触发 1
ee.emit("a", 2);   // 无输出(once 已移除)

console.log([1, 2, 2, 3].myFlat());          // [1, 2, 2, 3]
console.log(dedupe1([1, 2, 2, 3, 3, 3]));    // [1, 2, 3]
```
