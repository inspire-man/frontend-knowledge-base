# 7.6 路由(React Router)

> 卷:卷七 · 框架核心 · React
> 难度:⭐⭐ 进阶 | 阅读时间:15min

---

## 一、基本用法

```jsx
import { BrowserRouter, Routes, Route, Link } from "react-router-dom";

<BrowserRouter>
  <Routes>
    <Route path="/" element={<Home />} />
    <Route path="/user/:id" element={<User />} />
    <Route path="*" element={<NotFound />} />
  </Routes>
</BrowserRouter>
```

---

## 二、核心概念

| 概念 | 说明 |
|------|------|
| `useParams` | 拿动态参数 `:id` |
| `useNavigate` | 编程式跳转 |
| `Link` / `NavLink` | 声明式跳转 |
| 嵌套路由 | `<Outlet />` 渲染子路由 |

```jsx
const { id } = useParams();        // 读 /user/:id
const navigate = useNavigate();    // navigate("/list")
```

---

## 三、数据路由(React Router 6.4+)

```jsx
<Route path="/users" element={<Users />} loader={loadUsers} />
// loader 在渲染前取数据,组件用 useLoaderData() 读
```

> 数据路由把"**加载数据 → 渲染**"内置,配合错误边界(`errorElement`)、`defer` 流式,是 Remix 思路的前置。

---

## 小结

```
Routes/Route 声明路由;useParams 读参数;useNavigate 跳转
嵌套 <Outlet>;数据路由 loader 前置取数
```

## 面试题

**Q1:React Router 里如何做"路由懒加载"?**

```jsx
const User = lazy(() => import("./User"));   // 配合 React.lazy
<Route path="/user" element={<Suspense fallback={<>...</>}><User /></Suspense>} />
```

**Q2:`useNavigate` 和 `<Link>` 的区别?**

`<Link>` 是**声明式**(渲染成 `<a>`,适合导航);`useNavigate` 是**命令式**(在事件/副作用里代码触发跳转,适合提交表单后跳转等)。
