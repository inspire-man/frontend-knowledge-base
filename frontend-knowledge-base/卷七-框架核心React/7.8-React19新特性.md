# 7.8 React 19 新特性

> 卷:卷七 · 框架核心 · React

## 一、Action 与 `useActionState`(表单新范式)

React 19 引入 **Actions**:表单提交不再是"onSubmit + 手管 loading",而是声明式:

```jsx
const [state, formAction, isPending] = useActionState(submit, initialState);

<form action={formAction}>
  <input name="title" />
  <button disabled={isPending}>提交</button>
</form>
```

> `action` 表单会自动管理 pending 态、处理提交、支持乐观更新。

---

## 二、`use()` 与 `useOptimistic`

```jsx
// use():在组件里"读"Promise/Context(不再被 Hooks 规则限制,可在条件里用)
const data = use(promise);

// useOptimistic:先乐观显示,失败回滚
const [opt, add] = useOptimistic(list, (s, item) => [...s, item]);
```

## 三、其他关键变化

| 特性 | 说明 |
|------|------|
| **ref 可直接作 props** | `forwardRef` 不再必需 |
| **`<Context>` 直接是 Provider** | `<Theme value={...}>` 免 `.Provider` |
| **React Compiler** | 自动 `useMemo`/`useCallback`,免手动 memo |
| **Server Components 稳定** | 见 7.7 |

---

## 小结

```
React 19:Actions 表单 + useActionState / use() / useOptimistic
ref 作 props、Context 即 Provider、Compiler 自动 memo 化
```

## 面试题

**Q1:React 19 的 `action` 表单相比传统 `onSubmit` 有什么优势?**

内置**提交状态的自动管理**(isPending)、支持**乐观更新**、写法更声明式,省掉手写 loading/错误/重置;且与 **Server Actions**(服务端函数)天然衔接。

**Q2:React Compiler 做了什么,对开发有什么影响?**

在**编译期自动**给需要的地方加 memo 化(相当于自动 `useMemo`/`useCallback`),开发者**不必再手动做性能优化**,减少"该不该 memo"的心智负担,从默认"手写优化"转向"默认优化+按需打破"。
