# 8.2 泛型与高级类型

> 卷:卷八 · TypeScript
> 难度:⭐⭐⭐ 专家 | 阅读时间:30min

---

## 引言:从"写死类型"到"类型函数"

泛型让类型**参数化**,是 TS 从"类型标注工具"升级为"类型编程语言"的分水岭。之后的条件类型、映射类型、`infer`,本质上都是"对类型做运算"。

---

## 一、泛型:类型的"函数参数"

```ts
function identity<T>(value: T): T { return value; }
identity<string>("hi");      // T 被推断为 string
```

**约束 `extends`:**

```ts
function longest<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;   // 保证能访问 .length
}
```

---

## 二、keyof:取键的联合

```ts
type Keys = keyof { name: string; age: number };  // "name" | "age"

function get<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}
// get 的类型:key 必须是 obj 的键,返回值类型精确对应(这是最实用的泛型模式)
```

---

## 三、条件类型:类型里的"if"

```ts
type IsString<T> = T extends string ? true : false;
type A = IsString<"hi">;   // true
```

配合 `keyof` 是**分布式条件类型**(自动对联合的每个成员分别运算):

```ts
type Filter<T, U> = T extends U ? T : never;
type OnlyStr = Filter<"a" | 1 | "b" | 2, string>;  // "a" | "b"
```

---

## 四、infer:在条件类型里"捕获"类型

`infer` 用于**从类型里抽取某个部分**:

```ts
type Return<T> = T extends (...args: any[]) => infer R ? R : never;
type R = Return<(a: number) => string>;   // string

// 解构数组元素类型
type Element<T> = T extends (infer E)[] ? E : never;
type E = Element<number[]>;               // number
```

> `infer` 只能用在条件类型的 `extends` 分支里,代表"推断出那个位置的类型"。

---

## 五、映射类型:逐属性加工

```ts
type Partial<T> = { [K in keyof T]?: T[K] };
type Readonly<T> = { readonly [K in keyof T]: T[K] };
type Pick<T, K extends keyof T> = { [P in K]: T[P] };
type Record<K extends string | number | symbol, T> = { [P in K]: T };
```

**内置工具类型速查:**

| 工具 | 作用 |
|------|------|
| `Partial<T>` | 全可选 |
| `Required<T>` | 全必填 |
| `Readonly<T>` | 全只读 |
| `Pick<T, K>` | 挑属性 |
| `Omit<T, K>` | 删属性 |
| `Record<K, T>` | 造"键→值"映射 |
| `Exclude<T, U>` | 从 T 排除 U |
| `Extract<T, U>` | 取 T 与 U 交集 |
| `ReturnType<T>` | 取函数返回类型 |
| `Parameters<T>` | 取函数参数类型 |

---

## 六、模板字面量类型

```ts
type Prop = `${"on"}${"Click" | "Change"}`;  // "onClick" | "onChange"
type Getter<T> = `get${Capitalize<string & keyof T>}`;
```

> 常用来生成**事件名、路径、字符串枚举组合**的类型约束(如路由、CSS 变量名)。

---

## 小结

```
泛型:类型参数化 <T>,extends 约束,keyof 取键联合
条件类型:T extends U ? X : Y;分布式对联合逐成员运算
infer:在 extends 里捕获类型(ReturnType/Element 的实现)
映射类型:{ [K in keyof T]: ... },内置 Partial/Pick/Omit/Record 等
模板字面量:拼接/大小写变换生成字符串类型
```

## 面试题

**Q1:写一个 `First<T>` 取数组第一个元素类型**

```ts
type First<T extends any[]> = T extends [infer F, ...any[]] ? F : never;
type F = First<[string, number]>;  // string
```

**Q2:`Omit` 和 `Exclude` 的区别?**

`Omit<T, K>` 是对**对象属性**做减法(返回新对象类型);`Exclude<T, U>` 是对**联合类型**做减法(返回联合类型)。

**Q3:`keyof any` 是什么?**

`keyof any` = `string | number | symbol`,是对象键的全部可能类型,`Record<K, T>` 的 `K` 就约束为它。
