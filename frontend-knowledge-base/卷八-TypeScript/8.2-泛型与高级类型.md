# 8.2 泛型与高级类型

> 卷:卷八 · TypeScript
> 阅读时间:30min

---

## 引言:从"写死类型"到"类型函数"

泛型让类型**参数化**,是 TS 从"标注工具"到"类型编程语言"的分水岭。深挖要懂 **分布式条件类型** 与 **infer 的捕获**。

---

## 一、泛型 + 约束

```ts
function identity<T>(value: T): T { return value; }
function longest<T extends { length: number }>(a: T, b: T): T {
  return a.length >= b.length ? a : b;   // extends 约束保证能 .length
}
```

---

## 二、keyof + 泛型(最实用模式)

```ts
function get<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];           // 返回值类型精确对应
}
```

---

## 三、条件类型 + 分布式(底层)

```ts
type IsString<T> = T extends string ? true : false;

type Filter<T, U> = T extends U ? T : never;
type OnlyStr = Filter<"a" | 1 | "b" | 2, string>;  // "a" | "b"
```

**分布式条件类型(底层):** 当 `T` 是**裸类型参数 + 联合类型**时,`T extends U ? X : Y` 会**对联合的每个成员分别运算再合并**。这是 `Filter` 能"过滤联合"的原因(本质是 `map + filter` 的"分发")。

---

## 四、infer:捕获类型

```ts
type Return<T> = T extends (...args: any[]) => infer R ? R : never;
type Element<T> = T extends (infer E)[] ? E : never;
```

> `infer` 只能在条件类型的 `extends` 分支里,代表"推断出那个位置的类型"。

**协变(Covariance)与逆变(Contravariance):**

类型系统里"子类型关系如何随复合类型传递":

- **协变**:`Dog` 是 `Animal` 子类 → `Dog[]` 是 `Animal[]` 子类(方向保持)
- **逆变**:函数**参数位置方向反转**——`(Animal) => void` 是 `(Dog) => void` 的子类型

```ts
type F = (a: Animal) => void;
type G = (a: Dog) => void;
const g: G = (a: Animal) => {};   // ✅ 能处理 Animal 的函数,也能安全处理 Dog
```

> 为什么参数要逆变?为了**安全**:能处理"更大范围(Animal)"的函数,才能安全拿去处理"更小范围(Dog)"。TS 的 `strictFunctionTypes` 就是强制函数参数逆变检查(8.4)。

## 五、映射类型 + 内置工具

```ts
type Partial<T> = { [K in keyof T]?: T[K] };
type Readonly<T> = { readonly [K in keyof T]: T[K] };
type Pick<T, K extends keyof T> = { [P in K]: T[P] };
```

| 工具 | 作用 |
|------|------|
| `Partial/Required/Readonly` | 可选/必填/只读 |
| `Pick/Omit` | 挑/删属性 |
| `Record<K,T>` | 键值映射 |
| `Exclude/Extract` | 联合减/交 |
| `ReturnType/Parameters` | 取返回/参数类型 |

## 六、模板字面量类型

```ts
type Prop = `${"on"}${"Click" | "Change"}`;   // "onClick" | "onChange"
type Getter<T> = `get${Capitalize<string & keyof T>}`;
```

## 七、小结

```
泛型:类型参数化,extends 约束,keyof 取键联合
条件类型:T extends U ? X : Y;分布式=对联合逐成员分发
infer:extends 分支里捕获(ReturnType/Element)
映射:Partial/Pick/Omit/Record;模板字面量拼接/大小写
```

## 八、面试题

**Q1:写一个 First 取数组首元素类型**

```ts
type First<T extends any[]> = T extends [infer F, ...any[]] ? F : never;
```

**Q2:Omit 和 Exclude 的区别?**

`Omit<T,K>` 对**对象属性**做减法;`Exclude<T,U>` 对**联合类型**做减法。

**Q3:keyof any 是什么?**

`string | number | symbol`(对象键的全部可能类型),`Record<K,T>` 的 K 就约束为它。

**Q4:什么是"分布式条件类型"?什么时候触发?**

`T extends U ? X : Y` 中,当 `T` 是**裸类型参数(且有联合)**时,会对联合**逐成员分发**再合并。这是实现 `Exclude`/`Filter` 的原理。

**Q5:infer 有什么限制?**

只能在条件类型的 `extends` 分支里用,表示"推断出该位置的类型";不能在普通类型别名里直接 `infer X`。

**Q6:如何让条件类型"不分布式"?**

把 `T` 包一层(如 `[T] extends [U] ? ...`),破坏"裸类型参数"条件,就变成对**整个** `T` 判断,而非逐成员分发。
