## 二、知识地图(全景分层)

把前端知识体系抽象为 **6 层**,自底向上:

```
┌─────────────────────────────────────────────────────────────┐
│  L6 业务与工程实践层                                         │
│  性能优化 · 测试与质量 · Web 安全                            │
├─────────────────────────────────────────────────────────────┤
│  L5 框架与应用层                                             │
│  Vue3(响应式/编译/渲染) · React(Fiber/并发/Hooks) · SSR/RSC   │
│  状态管理 · 路由 · 组件体系                                  │
├─────────────────────────────────────────────────────────────┤
│  L4 语言与类型层                                             │
│  JavaScript 内核 · TypeScript 类型系统                        │
├─────────────────────────────────────────────────────────────┤
│  L3 工程化与构建层                                           │
│  模块化演进 · webpack/Vite/Rollup/esbuild/Rolldown/Rspack     │
│  Babel/SWC · 包管理 · Monorepo · CI/CD                       │
├─────────────────────────────────────────────────────────────┤
│  L2 运行时与平台层                                           │
│  浏览器原理(渲染/事件循环/V8) · Node.js/Bun/Deno · Web Worker │
│  网络协议(HTTP/HTTPS/HTTP2/3) · 浏览器通信 · 跨域/安全        │
├─────────────────────────────────────────────────────────────┤
│  L1 基础层                                                   │
│  HTML 语义化 · CSS(盒模型/布局/级联/动画) · 数据结构算法       │
└─────────────────────────────────────────────────────────────┘
```

**主线逻辑**:从「浏览器到底把代码怎么跑起来的」(L1/L2)→「代码怎么写更好、怎么组织」(L3/L4)→「应用怎么搭」(L5)→「怎么跑得快、稳、安全」(L6)。

> 扩展卷(卷十一)《AI Agent Harness 与提示词工程》横跨以上所有层之上,以 LLM 引擎重塑「人类如何驾驭软件」,独立成卷。

## 六、拓展性设计

为让这套目录能长期生长、不返工,预留以下扩展机制:

**1. 卷内追加(横向扩)**
- 每卷保留「+ 新章节」的能力,新特性只往对应卷里加,不新开卷。
- 例:Vue 出 3.6 新特性 → 追加 `6.8`;React 出 20 → 追加 `7.9`。

**2. 新增卷(纵向扩)**
- 当某个方向内容足够多时,才升级为独立卷。
- 候选储备:数据可视化(ECharts/D3/Canvas)、跨端(小程序/RN/Flutter)、WebGL/3D、低代码/表单引擎、音视频。

**3. 公共附录(统一挂载)**
- 「附录A · 手写系列」✅ 已建:Promise / call·apply·bind / 防抖节流 / 深拷贝 / pLimit / 发布订阅 / 数组方法
- 「附录B · 对比清单」✅ 已建:Vue vs React / 构建工具 / 网络请求 / 包管理与渲染模式
- 「附录C · 术语表」✅ 已建:缩写全称 + 高频术语中英对照速查

**4. 元数据(按需加)**
- 头部已精简为「卷 + 阅读时间」(克制表述,去掉冗余的难度/状态);未来若需多维度聚合,可按需回加 `标签`(学习路径/面试突击/专题)。

**5. 版本敏感标注**
- 涉及变动快的工具(Vite/Rolldown/Bun/React)的章节,头部标注「最后核对版本」,防止过时。

**6. 双轨编号**
- 主编号用「卷-章」固定不变(稳定引用、方便语雀目录树);新增内容只增不改号,避免旧链接失效。
