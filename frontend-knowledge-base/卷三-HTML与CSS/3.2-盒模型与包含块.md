## 引言:包含块,决定你百分比到底"相对于谁"

你原有的《你不知道的 CSS 之包含块》讲的就是这件事。大多数人知道盒模型,却不知道**百分比、绝对定位的参照物其实是"包含块",而不一定是父元素**。本章把它和盒模型一起讲透。

---

## 一、盒模型:两种 box-sizing

```css
.box {
  width: 100px;
  padding: 10px;
  border: 5px solid;
  box-sizing: content-box; /* 默认 */
}
```

| box-sizing | `width` 指谁 | 实际占宽 = |
|-----------|-------------|-----------|
| `content-box`(默认) | 内容区 | width + padding + border |
| `border-box` | 边框盒整体 | width(已含 padding+border) |

> 工程惯例:`* { box-sizing: border-box; }`,这样设置 width 就是最终可见宽度,布局更好算。

---

## 二、什么是包含块(Containing Block)

> **元素的尺寸/位置/百分比值,是相对它的"包含块"来计算的。**

换句话说:`width: 50%` 的 50%,是"包含块宽度"的 50%,**不是父元素的 50%**——只是"大多数时候包含块恰好等于父元素内容区"。

---

## 三、包含块的两大类判定规则

### 1. 根元素(<html>)→ 初始包含块

**初始包含块(initial containing block)** 大小 = **视口 viewport**,基点在画布左上角。它是绝对/固定定位的默认参照。

### 2. 非根元素 → 看 position

| position | 包含块 |
|----------|--------|
| `static` / `relative` | 最近**块容器**的**内容区**(content area)边缘 |
| `fixed` | 视口(viewport) |
| `absolute` | 最近**非 static 祖先**(absolute/relative/fixed/sticky)的**内边距区(padding box)**边缘 |

**三条里最容易错的是 absolute**(你原文重点):

```html
<div class="container">   <!-- position: relative -->
  <div class="item">      <!-- 无定位 -->
    <div class="item2">   <!-- position: absolute -->
```

`item2` 的包含块是 **`.container`(最近的非 static 祖先),而不是 `.item`**——除非 `.item` 也设置了定位。

### 3. 特例:这些属性也能"制造"包含块

当祖先出现以下任一,`absolute`/`fixed` 的包含块会变成**这个祖先的内边距区**(即使它是 static):

```css
transform: rotate(0deg);   /* transform 非 none */
will-change: transform / perspective;
filter: blur(5px);         /* filter 非 none */
contain: paint;
```

```html
<div class="item" style="transform: rotate(0deg)">
  <div class="item2" style="position: absolute">
  <!-- item2 的包含块变成 .item,因为你给了 transform -->
```

> 常见坑:给容器加个 `transform` 做动画,里面 absolute 定位的元素突然"跑偏"了——就是包含块变了。

---

## 四、为什么"块容器"≠"父元素"(你原文的 strong1 例子)

```html
<div id="div1"><p id="p2"><em id="em1"><strong id="strong1">…</strong></em></p></div>
```

`strong1` 的 father 是 `em1`,但 `em1` 是**行内元素、不是块容器**,所以 `strong1` 的包含块是**最近的块容器 `p2`**。记住关键词:**"最近的块容器",不是"最近的父元素"**。

---

## 五、小结

```
盒模型:content-box(默认) vs border-box(推荐全局用 border-box)

包含块 = 百分比/定位的参照物
├─ 根元素 → 初始包含块 = 视口
├─ static/relative → 最近块容器的内容区
├─ fixed → 视口
├─ absolute → 最近非 static 祖先的 padding 区
└─ 特例 → transform/will-change/filter/contain 也能充当包含块
易错:绝对定位看"最近非 static 祖先",不看最近的父元素;且是"块容器"
```

## 六、面试题

**Q1:`position: absolute` 元素设置 `width: 50%`,是相对谁?**

相对它的**包含块**:即最近的非 static 定位祖先的 **padding box** 宽度。若没有这样的祖先,则相对**初始包含块(视口)**。注意是 padding box(含 padding,不含 border),且不是简单地"相对父元素"。

**Q2:下面 `.box` 的宽高是多少?**

```html
<div class="wrap" style="position:relative; width:500px; padding:20px">
  <div class="box" style="position:absolute; width:50%; height:50%"></div>
</div>
```

<details>
<summary>答案</summary>

```js
// .box 的包含块是 .wrap 的 padding box:宽 500px(含 padding),高取决于内容/未定
// width:50% = 500 * 50% = 250px
// height:50%:父未显式设高,高度百分比会"塌",需父有确定高度才有效
```
</details>
