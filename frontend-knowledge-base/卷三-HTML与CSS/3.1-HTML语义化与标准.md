# 3.1 HTML 语义化与标准

---

## 引言:HTML 不只是一堆 div

语义化 HTML 是「用对的标签表达对的意思」。它直接决定三件事:**SEO(搜索引擎读不读得懂)、可访问性(读屏器/键盘用户用不用得了)、可维护性(人看得清不清)**。这也是面试里容易被忽略、却最能体现"职业素养"的一题。

---

## 一、什么是语义化

> 用**具有明确含义的标签**去承载内容,而不是满屏 `<div>` / `<span>`。

```html
<!-- ❌ 反例:全部 div,机器和人都要靠 class 猜 -->
<div class="header">…</div>
<div class="main">…</div>
<div class="footer">…</div>

<!-- ✅ 正例:一眼知道结构 -->
<header>…</header>
<main>…</main>
<footer>…</footer>
```

---

## 二、常用语义标签速查

| 标签 | 含义 | 说明 |
|------|------|------|
| `<header>` | 页眉/区块头 | 通常在顶部 |
| `<nav>` | 导航 | 链接集合 |
| `<main>` | 主内容 | 页面**唯一**,核心内容 |
| `<section>` | 章节 | 有标题的独立区块 |
| `<article>` | 文章 | **可独立分发**的内容(如一篇博客) |
| `<aside>` | 侧边/附属 | 与主内容相关但非核心 |
| `<footer>` | 页脚 | 版权/链接等 |

**section vs article 的区分(高频):**

> 判断标准:这段内容**脱离当前页面还能否独立存在/被引用**?能 → `article`;只是页面内部的一个板块 → `section`。

## 三、可访问性(Accessibility, a11y)

### 1. 图片 alt

```html
<img src="chart.png" alt="2024 年营收增长柱状图">
<!-- 空 alt(纯装饰图):alt="" 让读屏器跳过 -->
```

### 2. 表单 label 关联

```html
<label for="email">邮箱</label>
<input id="email" type="email">
<!-- label 的 for 关联 input 的 id,点击 label 可聚焦输入框,读屏器能读出"邮箱" -->
```

### 3. ARIA 属性(给"无语义的动态组件"补语义)

当原生标签表达不了时,用 ARIA 补齐:

```html
<button aria-expanded="true" aria-controls="menu">展开菜单</button>
<div role="dialog" aria-modal="true">…</div>
```

> 原则:**能用原生语义标签解决,就别上 ARIA**。ARIA 是"补丁",不是首选。

### 4. 键盘可操作 & 焦点

- 交互元素用原生 `<button>`/`<a>`,天然支持键盘(Tab/Enter)
- 用 `div` 加 `onClick` 却不加 `tabindex`/`role`,键盘用户就点不到 —— 可访问性反例

## 四、SEO 相关的语义细节

1. **标题层级**:`<h1>` 唯一且概括页主题,`h2→h6` 层层嵌套,别跳级
2. **meta 信息**:

```html
<title>关键的页面标题</title>
<meta name="description" content="摘要描述">
<meta name="viewport" content="width=device-width, initial-scale=1">
```

3. **结构化数据**(JSON-LD):帮搜索引擎识别类型(文章/商品/评分)

## 五、新标准标签与属性(挑常用)

```html
<details>
  <summary>点击展开</summary>
  折叠内容(原生手风琴,无需 JS)
</details>

<dialog open>原生对话框</dialog>

<input type="search">         <!-- 搜索框 -->
<input type="range">          <!-- 滑块 -->
<picture>                     <!-- 响应式图片 -->
  <source srcset="big.webp" media="(min-width: 768px)">
  <img src="small.jpg" alt="">
</picture>
```

## 六、小结

```
语义化 = 用对的标签表达对的意思
├─ 结构:header/nav/main/section/article/aside/footer
├─ 价值:SEO ↑ / 可访问性 ↑ / 可维护性 ↑
├─ a11y:alt、label-for、ARIA(补丁)、键盘焦点
└─ 细节:article 可独立分发 / h1 唯一 / meta 完善
```

## 七、面试题

**Q1:`<section>` 和 `<div>` 有什么本质区别?**

`section` 有**语义**:表示带主题的章节,会被搜索引擎/读屏器当作结构节点;`div` 是**无语义**的通用容器,只用于布局分组。能用 `section` 就别用 `div` 堆。

**Q2:如何提升一个页面的可访问性?至少说四点**

① 图片加 `alt`(装饰图留空);② 表单用 `label for` 关联;③ 交互用原生按钮/链接,保证键盘可操作;④ 语义标签 + 合理标题层级;⑤ 需要时补 `role`/`aria-*`;⑥ 关注对比度与焦点可见。
