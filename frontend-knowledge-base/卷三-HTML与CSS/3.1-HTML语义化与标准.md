# 3.1 HTML 语义化与标准

> 卷:卷三 · HTML 与 CSS
> 难度:⭐ 基础 | 阅读时间:15min | 状态:已深化

---

## 引言:HTML 不只是一堆 div

语义化 HTML 是"用对的标签表达对的意思"。它直接决定三件事:**SEO、可访问性、可维护性**。

---

## 一、什么是语义化

**用具有明确含义的标签承载内容,而非满屏 `<div>`:**

```html
<!-- ❌ 全 div,机器和人靠 class 猜 -->
<div class="header">…</div>

<!-- ✅ 一眼知道结构 -->
<header>…</header>
```

---

## 二、页面结构(一图)

```mermaid
flowchart TD
    A[html] --> B[head]
    A --> C[body]
    C --> D[header 页眉]
    C --> E[nav 导航]
    C --> F[main 主内容(唯一)]
    F --> G[article 可独立分发]
    F --> H[section 章节]
    C --> I[aside 侧边栏]
    C --> J[footer 页脚]
```

**section vs article(高频):** 内容**脱离页面能否独立存在/被引用**?能 → `article`;只是页面内部板块 → `section`。

---

## 三、可访问性(Accessibility)

```html
<img src="chart.png" alt="2024 营收柱状图">   <!-- 图片 alt -->
<label for="email">邮箱</label>                <!-- label 关联 -->
<input id="email" type="email">

<button aria-expanded="true" aria-controls="menu">展开</button>  <!-- ARIA -->
<div role="dialog" aria-modal="true">…</div>
```

> 原则:**能用原生语义标签就别上 ARIA**(ARIA 是补丁,不是首选);交互用原生 `<button>`/`<a>` 保证键盘可操作。

---

## 四、为什么语义化影响 SEO 与 a11y

> 搜索引擎爬虫和读屏器**都"读"标签结构**:语义标签让爬虫知道哪里是正文、哪里是导航(h1 唯一、层级正确),让读屏器知道如何播报(role、label、alt)。`<div>` 对所有机器都是"无语义",等于**放弃了对机器表达结构**。

---

## 五、SEO 相关细节

- `<h1>` 唯一概括主题,`h2→h6` 层层嵌套
- `<title>` + `<meta name="description">` 完善
- 结构化数据(JSON-LD)帮搜索引擎识别类型

---

## 六、小结

```
语义化 = 用对的标签表达对的意思
结构:header/nav/main/section/article/aside/footer(article 可独立)
价值:SEO ↑ / a11y ↑ / 可维护 ↑
a11y:alt、label-for、ARIA(补丁)、键盘焦点
```

---

## 七、面试题

**Q1:`<section>` 和 `<div>` 的本质区别?**

`section` 有**语义**(有主题的章节,被搜索引擎/读屏器当结构节点);`div` 是**无语义**通用容器。能表达结构就用语义标签。

**Q2:如何提升页面可访问性?至少四点**

① 图片 `alt`(装饰图留空);② 表单 `label for` 关联;③ 原生按钮/链接保证键盘可操作;④ 语义标签 + 合理标题层级;⑤ 需要时补 `role`/`aria-*`;⑥ 关注对比度与焦点可见。
