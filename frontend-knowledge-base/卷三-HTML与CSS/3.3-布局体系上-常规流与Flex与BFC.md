## 引言:从"块和行"到"上帝给的 Flex"

CSS 布局的心法只有三层:**常规流(块/行内)→ BFC(格式化上下文)→ Flex/Grid(现代布局)**。本章讲前三者,把"外边距折叠""清除浮动"这些老痛点一次说清。

---

## 一、常规流:块级 vs 行内

| | 块级(block) | 行内(inline) |
|---|-------------|--------------|
| 典型元素 | `div`/`p`/`h1` | `span`/`a`/`em` |
| 排列 | 纵向,独占一行 | 横向,一行内流式 |
| 盒模型 | 宽高/上下 margin 生效 | 宽高难生效,上下 margin 弱 |

> 转换:`display: block / inline / inline-block`。`inline-block` = 行内排布 + 块级盒模型(可设宽高)。

---

## 二、BFC(块级格式化上下文)

**BFC** 是一块"独立渲染区域":内部的布局**不影响外部**,外部的也进不来。它是破解"外边距折叠""浮动塌陷"的钥匙。

### 1. 怎么触发 BFC

```css
overflow: hidden / auto / scroll;   /* 最常见 */
display: flow-root;                 /* 现代推荐,无副作用 */
position: absolute / fixed;
float: left / right;
display: inline-block / flex / grid;/* flex/grid 也会创建 */
```

> `display: flow-root` 是"只为产生 BFC"而生的,不会像 `overflow: hidden` 那样误裁剪内容。

### 2. 作用一:解决"外边距折叠(Margin Collapse)"

相邻块级元素的上下 margin 会**取较大值合并**,而不是相加:

```css
p { margin: 20px 0; }  /* 上下两个 p 之间 = 20px,不是 40px */
```

给父元素触发 BFC,就能阻断父子的 margin 折叠:

```css
.container { display: flow-root; } /* 子元素 margin 不再"漏"出去 */
```

### 3. 作用二:清除浮动(父高度塌陷)

子元素 `float` 后脱离常规流,父元素高度塌成 0。让父元素成为 BFC 即可**包裹浮动子元素**:

```css
.container { overflow: hidden; }  /* 或 display: flow-root */
```

> 这也是"清除浮动"除了 `clear: both` 伪元素法之外,更现代的解法。

## 三、Flexbox:一维布局之王

### 1. 核心概念

```
主轴(main axis) ────▶(由 flex-direction 决定)
交叉轴(cross axis) ↑

容器属性 vs 项目属性
```

### 2. 容器(flex container)常用属性

```css
.container {
  display: flex;
  flex-direction: row;          /* 主轴方向:row/column/reverse */
  justify-content: space-between; /* 主轴对齐:center/space-between/space-around */
  align-items: center;            /* 交叉轴对齐:center/flex-start/stretch */
  flex-wrap: wrap;                /* 换行 */
  gap: 12px;                      /* 间距(现代,替代 margin 负值) */
}
```

### 3. 项目(flex item)核心属性

| 属性 | 作用 |
|------|------|
| `flex-grow` | 放大比例(默认 0) |
| `flex-shrink` | 缩小比例(默认 1) |
| `flex-basis` | 基准尺寸(分配前的主轴尺寸) |
| `flex: 1` | = `flex-grow:1, shrink:1, basis:0%` |

```css
.item { flex: 1; }  /* 均分剩余空间,经典等宽布局 */
```

**`flex:1` 为什么是 `basis: 0%` 而不是 `auto`(高频)?**

- `flex: 1` → `1 1 0%`:忽略内容固有宽度,**纯粹按比例均分剩余空间**
- `flex: auto` → `1 1 auto`:先按内容大小分配,再分剩余空间 → 内容长短不一导致宽度不均

> 要"真·等分",用 `flex: 1`(`basis: 0%`)。

## 四、小结

```
常规流:块(纵向)/ 行内(横向)/ inline-block(行内+块盒)

BFC = 独立渲染区域
├─ 触发:overflow(≠visible)/ flow-root / float / absolute / flex
├─ 作用:阻断 margin 折叠 + 包裹浮动(清浮动)+ 野兽隔离
└─ 现代首选:display: flow-root

Flex:一维布局
├─ 容器:flex-direction / justify-content / align-items / gap
└─ 项目:flex-grow/shrink/basis;flex:1 = 1 1 0%(真等分)
```

## 五、面试题

**Q1:什么是 BFC?触发条件?三个应用场景?**

BFC(块级格式化上下文)是独立的布局区域,内外互不影响。触发:`overflow: hidden/auto`、`display: flow-root/flex/grid`、`float`、`position: absolute/fixed`。应用:① 清除浮动(父包裹浮动子);② 阻止外边距折叠;③ 两栏布局时隔离,防止浮动元素重叠。

**Q2:`flex: 1` 和 `flex: auto` 的区别?**

`flex: 1` = `1 1 0%`(flex-basis 为 0),忽略内容宽度按比例均分 → 各项目等宽。`flex: auto` = `1 1 auto`(basis 为内容宽度),先按内容占位再分剩余,内容长短不一则宽度不等。
