## 二、解构与展开

```js
// 解构赋值
const { name, age = 18 } = user;      // 对象解构 + 默认值
const [first, , third] = arr;         // 数组解构,可跳位
const { a: aa, ...rest } = obj;       // 重命名 + 剩余

// 展开运算符
const merged = { ...a, ...b };        // 浅合并对象
const copy = [...arr];                // 浅拷贝数组(嵌套引用仍是浅的)
const max = Math.max(...nums);        // 展开作参数
```

> rest 参数(收集)与 spread(展开)是同一个 `...`,看位置:函数形参里是 rest,调用/字面量里是 spread。

## 五、对象增强

```js
// 属性/方法简写
const obj = { name, say() {} };       // 等价 { name: name, say: function(){} }

// 计算属性名
const key = "x";
const o = { [key]: 1 };               // { x: 1 }

// Object 静态方法
Object.assign(target, src)            // 浅合并(旧)
Object.keys / values / entries        // 键/值/键值对数组
const { ...rest } = obj               // 新式浅拷贝更常用
```

### 可选链 `?.` 与空值合并 `??`(ES2020,高频)

```js
const city = user?.address?.city;     // 链上任意一环为 null/undefined 就返回 undefined,不报错
const v = obj?.name ?? "默认值";       // ?? 只在 null/undefined 时兜底(区别于 || 对 0/""/false 也兜底)
```

## 六、数组新方法

```js
arr.map / filter / reduce            // 老三样,链式
arr.find(fn)        // 找第一个满足的「元素」
arr.findIndex(fn)   // 找「下标」
arr.some / every    // 任一 / 全部满足
arr.includes(v)     // 是否包含(替代 indexOf !== -1)
arr.flat(n)         // 拍平嵌套数组,Infinity 全拍平
arr.flatMap(fn)     // map + flat(1)
arr.at(-1)          // 取最后一个(支持负索引)
Array.from(iterable) // 可迭代/类数组 → 真数组
```

## 七、Map / Set / WeakMap(见 1.3 派生的数据结构)

```js
const map = new Map([["k", "v"]]);    // 键可以是任意类型;有 .size / .get / .set
map.get("k");                          // "v"

const set = new Set([1, 2, 2, 3]);    // 去重;.has / .add / .size
[...set];                              // [1, 2, 3]

// WeakMap:键必须是对象,且是弱引用(不阻止 GC)
const wm = new WeakMap();
wm.set(obj, meta);                     // obj 无其他引用时可被回收,常用于给对象挂私有元数据
```

## 九、Proxy / Reflect(ES6,框架基石)

`Proxy` 拦截对象操作,是 Vue3 响应式的底层:

```js
const target = { count: 0 };
const proxy = new Proxy(target, {
  get(obj, key) { console.log("读", key); return obj[key]; },
  set(obj, key, val) { console.log("写", key, val); obj[key] = val; return true; },
});
proxy.count;       // 读 count → 0
proxy.count = 1;   // 写 count 1
```

`Reflect` 是与 `Proxy` 配套的"默认行为"反射 API:`Reflect.get/set/has`,让拦截器里能简洁地走原始行为。

## 十、小结速查表

| 需求 | 语法 |
|------|------|
| 块级变量 | `let/const` |
| 安全取深层属性 | `a?.b?.c` |
| 空值兜底(不含 falsy) | `a ?? 默认` |
| 浅拷贝对象/数组 | `{...o}` / `[...a]` |
| 去重 | `new Set(arr)` |
| 拍平 | `arr.flat(Infinity)` |
| 对象私有元数据 | `WeakMap` |
| 拦截对象读写(Vue3 原理) | `Proxy` + `Reflect` |

## 十一、面试题

**Q1:`??` 和 `||` 的区别?**

```js
0 || "兜底"    // "兜底"  ← || 会把 0/""/false 都当假
0 ?? "兜底"    // 0       ← ?? 只认 null/undefined
```

**Q2:`Proxy` 为什么能实现响应式,而 `Object.defineProperty`(Vue2)有什么局限?**

`Object.defineProperty` 只能**逐属性**拦截 get/set,新增属性、删除属性、数组下标变化都监听不到,需要 `Vue.set` 补丁;`Proxy` 能拦截**任意属性**的增删改查 + 数组方法,Vue3 因此抛弃了 defineProperty。
