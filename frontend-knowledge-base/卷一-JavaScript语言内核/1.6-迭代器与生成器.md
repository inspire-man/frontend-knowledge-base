## 引言:`for...of` 为什么能遍历数组

因为数组是"可迭代对象"。这里藏着 JS 的一个底层协议:**迭代协议**。理解它,才能搞懂 `for...of`、展开运算符、以及 `async/await` 的实现来源——**生成器**。

---

## 一、两个协议:Iterator 与 Iterable

### 1.1 Iterator(迭代器)

一个拥有 `next()` 方法的对象,每次调用返回 `{ value, done }`:

```js
function makeIterator(arr) {
  let i = 0;
  return {
    next() {
      return i < arr.length
        ? { value: arr[i++], done: false }
        : { value: undefined, done: true };
    },
  };
}
const it = makeIterator([1, 2, 3]);
it.next(); // { value: 1, done: false }
it.next(); // { value: 2, done: false }
it.next(); // { value: 3, done: false }
it.next(); // { value: undefined, done: true }
```

### 1.2 Iterable(可迭代对象)

一个对象有 `Symbol.iterator` 方法,该方法返回一个迭代器,它就是**可迭代的**。数组、字符串、Map、Set、`arguments`、NodeList 都内置了它。

---

## 二、`for...of` 的原理

`for...of` 本质是不断调用 `Symbol.iterator` 拿到的 `next()`,直到 `done` 为 true:

```js
for (const v of arr) { /* ... */ }

// 等价于
const iter = arr[Symbol.iterator]();
let r = iter.next();
while (!r.done) {
  const v = r.value;
  /* ... */
  r = iter.next();
}
```

**与 `for...in` 的区别(高频):**

| | 遍历 | 适用 |
|---|------|------|
| `for...of` | 遍历**值**,依赖迭代协议 | 数组/字符串/Map/Set/可迭代对象 |
| `for...in` | 遍历**可枚举的键**(含原型链) | 对象(不推荐用来遍历数组) |

**让普通对象可迭代:**

```js
const obj = {
  from: 1, to: 3,
  [Symbol.iterator]() {
    let cur = this.from;
    const { to } = this;
    return { next: () => (cur <= to ? { value: cur++, done: false } : { value: undefined, done: true }) };
  },
};
for (const n of obj) console.log(n); // 1 2 3
console.log([...obj]);              // [1, 2, 3] ← 展开运算符也走迭代协议
```

## 三、生成器 Generator

生成器是一种"**能中途暂停**"的函数,`function*` 声明,`yield` 暂停点:

```js
function* gen() {
  yield 1;
  yield 2;
  return 3;   // return 的值会体现在 { value: 3, done: true }
}
const g = gen();
g.next(); // { value: 1, done: false }
g.next(); // { value: 2, done: false }
g.next(); // { value: 3, done: true }   ← return 后结束
```

**核心特性:双向通信 —— `next()` 能把值传回 `yield`**

```js
function* talk() {
  const a = yield "第一次给我个值";
  const b = yield `收到:${a},再给我个值`;
  return `收到:${b},结束`;
}
const g = talk();
g.next();          // { value: "第一次给我个值", done: false }
g.next("大王");    // { value: "收到:大王,再给我个值", done: false }
g.next("阿北");    // { value: "收到:阿北,结束", done: true }
```

## 四、生成器的应用

| 场景 | 说明 |
|------|------|
| **惰性/无限序列** | 需要才计算,如斐波那契、分页拉取 |
| **异步流程控制(co 模型)** | `yield` 暂停等异步,`next` 继续 → `async/await` 的前身 |
| **实现自定义迭代器** | 用 `function*` 代替手写 `next` |

**惰性无限序列:**

```js
function* fibonacci() {
  let [a, b] = [0, 1];
  while (true) {
    yield a;
    [a, b] = [b, a + b];
  }
}
const f = fibonacci();
f.next().value; // 0
f.next().value; // 1
f.next().value; // 1
f.next().value; // 2  ← 要多少算多少,不占内存
```

**`async/await` 由生成器而来(简化版演示):**

```js
function* asyncFlow() {
  const a = yield fetch("/a");        // 暂停,等待
  const b = yield fetch(`/b?q=${a}`); // 恢复后继续
  return b;
}
// 配合一个 runner:自动 next,遇到 Promise 就等它完成再 next
// —— 这正是 async/await 的实现思想(babel 早期也是这么编译的)
```

## 五、小结

```
迭代协议
├─ Iterator:有 next(),返回 {value, done}
└─ Iterable:有 [Symbol.iterator](),返回迭代器

for...of / 展开运算符 / 解构 → 都走「拿到迭代器 → 循环 next 到 done」

生成器 function* + yield
├─ 能暂停/恢复,next 可双向传值
├─ 应用:惰性序列 / co 异步流程
└─ 本质:async/await 的实现来源
```

## 六、面试题

**Q1:`[...str]` 和 `Array.from(str)` 有何异同?**

两者都能把可迭代对象(如字符串)转数组。`Array.from` 额外支持**类数组对象**(有 `length` 但无迭代协议)和第二个 map 函数:

```js
const likeArray = { 0: "a", 1: "b", length: 2 };
console.log([...likeArray]);        // TypeError(不可迭代)
console.log(Array.from(likeArray)); // ["a", "b"]  ✅
```

**Q2:如何让生成器产出两次就会被 `break` 的中断语义?**

`for...of` 遇到 `break`/`return`/异常会调用迭代器的 `return()` 方法;生成器里用 `try/finally` 能捕获这个"提前结束":

```js
function* g() {
  try { yield 1; yield 2; yield 3; }
  finally { console.log("被提前关闭"); }
}
for (const v of g()) { if (v === 2) break; } // 打印"被提前关闭"
```
