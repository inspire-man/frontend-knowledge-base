# 1.4 this 绑定与调用

## 引言:`this` 是运行时决定的

`this` 是 JS 里唯一一个"**看调用方式,不看定义位置**"的关键字(箭头函数除外)。它指向**"谁在调用这个函数"**。记不住规则,就靠四张牌 + 一张特殊牌。

---

## 一、四大绑定规则(一图流)

```mermaid
flowchart TD
    A[函数被调用] --> B{调用方式?}
    B -->|new Foo()| C[new 绑定 → 新对象]
    B -->|call / apply / bind| D[显式绑定 → 指定对象]
    B -->|obj.foo()| E[隐式绑定 → obj]
    B -->|裸调用 foo()| F[默认绑定 → 全局/undefined]
```

### 1. 默认绑定:独立调用

```js
function foo() { console.log(this); }
foo(); // 浏览器 window;严格模式 undefined
```

### 2. 隐式绑定:对象调用

```js
const obj = {
  name: "大王",
  say() { console.log(this.name); },
};
obj.say(); // "大王" ← this 是 obj

// 经典丢失陷阱
const fn = obj.say;
fn(); // undefined ← 变成默认绑定
```

### 3. 显式绑定:call / apply / bind

```js
function greet(g, e) { console.log(g + this.name + e); }
const me = { name: "阿北" };
greet.call(me, "hi ", "!");      // call:逐个传参
greet.apply(me, ["hi ", "!"]);   // apply:数组传参
const bound = greet.bind(me, "yo "); // bind:返回新函数
bound("?");                       // "yo 阿北?"
```

### 4. new 绑定

```js
function Person(name) { this.name = name; }
const p = new Person("大王");   // this = new 出的新对象
```

---

## 二、优先级

> **new > 显式绑定 > 隐式绑定 > 默认绑定**

---

## 三、特殊牌:箭头函数

**箭头函数没有自己的 `this`**,捕获**定义时所在词法作用域**的 `this`,且**无法被 call/apply/bind 改变**。

```js
const obj = {
  name: "大王",
  say() {
    setTimeout(() => console.log(this.name), 0);   // "大王"(继承 say 的 this)
  },
  sayWrong() {
    setTimeout(function () { console.log(this.name); }, 0); // undefined(默认绑定)
  },
};
```

**为什么这样设计?** 普通函数的 `this` 是**运行时动态绑定**的,回调/定时器里极易丢失(变成全局);箭头函数用**词法 this**"锁死"定义处的 this,天生适合回调、事件、嵌套函数——省去 `const self = this` 或 `bind(this)` 的样板。这正是箭头函数被 React/Vue 回调广泛使用的原因。

---

## 四、小结

```
this 绑定:默认(全局)/ 隐式(obj.foo)/ 显式(call/apply/bind)/ new(新对象)
优先级:new > 显式 > 隐式 > 默认
箭头函数:无自己的 this,继承定义处外层 this,不可被 bind 改变
```

## 五、面试题

**Q1:下面输出什么?**

```js
const length = 10;
function fn() { console.log(this.length); }
const obj = { length: 5, method(fn) { fn(); arguments[0](); } };
obj.method(fn, 1);
// 10, 2(fn() 默认绑定→window.length=10;arguments[0]() 隐式绑定→arguments.length=实参个数2)
```

**Q2:手写 `call` / `bind`?**

```js
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx ?? globalThis;
  const fn = Symbol("fn");
  ctx[fn] = this;
  const res = ctx[fn](...args);
  delete ctx[fn];
  return res;
};

Function.prototype.myBind = function (ctx, ...args) {
  const self = this;
  return function (...rest) {
    return self.apply(this instanceof self ? this : ctx, args.concat(rest));
  };
};
```

**Q3:箭头函数为什么不能用作构造函数?**

因为它**没有自己的 `this`** 和 `prototype`,也没有 `arguments`/`new.target`;`new` 绑定需要一个能"指向新对象"的 this 与 prototype,箭头函数都没有,所以 `new` 它会报错。
