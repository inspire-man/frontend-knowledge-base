# 1.4 this 绑定与调用

## 引言:`this` 是运行时决定的

`this` 是 JS 里唯一一个"**看调用方式,不看定义位置**"的关键字(箭头函数除外)。它不指"函数本身",也不指"函数的作用域",而是**指向"谁在调用这个函数"**。记不住规则,就靠四张牌 + 一张特殊牌。

---

## 一、四大绑定规则

### 1. 默认绑定:独立调用 → 全局 / undefined

```js
function foo() {
  console.log(this);
}
foo(); // 浏览器下是 window;严格模式下是 undefined
```

裸调用 `foo()`,没有任何对象前缀,走默认绑定。

### 2. 隐式绑定:对象调用 → 那个对象

```js
const obj = {
  name: "大王",
  say() { console.log(this.name); },
};
obj.say(); // "大王"  ← this 是 obj(谁点出来就是谁)
```

**经典丢失陷阱**:把方法赋值给变量后独立调用,`this` 就丢了。

```js
const fn = obj.say;
fn(); // undefined  ← 变成了默认绑定,this 指向全局,拿不到 name
```

### 3. 显式绑定:call / apply / bind

```js
function greet(greeting, ending) {
  console.log(greeting + this.name + ending);
}
const me = { name: "阿北" };

greet.call(me, "hi ", "!");   // call:逐个传参
greet.apply(me, ["hi ", "!"]);// apply:数组传参
const bound = greet.bind(me, "yo "); // bind:返回新函数,可继续传剩余参数
bound("?");                   // "yo 阿北?"
```

> `call`/`apply` 立即执行;`bind` 只绑定、返回新函数,**不立即执行**。

### 4. new 绑定:构造函数调用 → 新对象

```js
function Person(name) {
  this.name = name; // this 指向 new 出来的新对象
}
const p = new Person("大王");
console.log(p.name); // "大王"
```

---

## 二、优先级

> **new > 显式绑定 > 隐式绑定 > 默认绑定**

```js
// 显式绑定 vs 隐式绑定:显式赢
obj.say.call(other); // this = other

// new vs 显式:new 赢(但很少同时用)
const p2 = new (Person.bind(other))("x"); // this = 新对象
```

---

## 三、特殊牌:箭头函数

**箭头函数没有自己的 `this`**,它捕获的是**定义时所在词法作用域**的 `this`(即外层函数的 this),且**无法被 call/apply/bind 改变**。

```js
const obj = {
  name: "大王",
  say() {
    setTimeout(() => {
      console.log(this.name); // "大王"  ← 箭头函数继承了 say 的 this
    }, 0);
  },
  sayWrong() {
    setTimeout(function () {
      console.log(this.name); // undefined  ← 普通函数,this 是全局
    }, 0);
  },
};
obj.say();
obj.sayWrong();
```

**适用场景**:回调、定时器、事件处理器里想沿用外层 `this` 时用箭头函数最省心;需要动态 `this`(如给对象加方法)就用普通函数。

---

## 四、小结

```
this 绑定规则
├─ 默认:独立调用 → 全局/undefined(严格)
├─ 隐式:obj.foo() → obj(易丢失)
├─ 显式:call/apply/bind → 指定对象(bind 返回新函数)
├─ new:构造调用 → 新对象
└─ 优先级:new > 显式 > 隐式 > 默认

箭头函数:无自己的 this,继承定义处外层 this,不可被 call/bind 改变
```

## 五、面试题

**Q1:下列输出?**

```js
const length = 10;
function fn() { console.log(this.length); }
const obj = { length: 5, method(fn) { fn(); arguments[0](); } };
obj.method(fn, 1);
```

<details>
<summary>答案</summary>

```js
// fn()          → 默认绑定,this 指向全局(window.length = 10)→ 10
// arguments[0]() → 隐式绑定,arguments 对象.length = 实参个数 = 2
// 输出:10, 2
```
</details>

**Q2:手写 `call` / `bind`(高频)**

```js
// 手写 call
Function.prototype.myCall = function (ctx, ...args) {
  ctx = ctx ?? globalThis;         // null/undefined 时兜底
  const fn = Symbol("fn");         // 用唯一 key 防覆盖
  ctx[fn] = this;                  // 把当前函数挂到 ctx 上,实现隐式绑定
  const res = ctx[fn](...args);
  delete ctx[fn];
  return res;
};

// 手写 bind
Function.prototype.myBind = function (ctx, ...args) {
  const self = this;
  return function (...rest) {
    // 兼容 new 的情况:被 new 调用时 this 是新对象
    return self.apply(this instanceof self ? this : ctx, args.concat(rest));
  };
};
```
