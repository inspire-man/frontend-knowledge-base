## 引言:SPA 的"多页面",靠路由模拟

单页应用(SPA)只有一个 HTML,靠前端路由**在地址变化时切换组件**,不刷新页面。Vue Router 做三件事:**匹配路径 → 渲染组件 → 管理导航**。

---

## 一、两种路由模式

| 模式 | URL 形态 | 原理 | 部署要求 |
|------|---------|------|---------|
| **history** | `/user/123`(干净) | HTML5 History API(`pushState`) | 需服务器 **fallback 到 index.html** |
| **hash** | `/index.html#/user/123` | `hashchange` 事件 | 无需服务端配置 |

```js
import { createRouter, createWebHistory, createWebHashHistory } from "vue-router";
const router = createRouter({
  history: createWebHistory(),        // 或 createWebHashHistory()
  routes: [
    { path: "/", component: Home },
    { path: "/user/:id", component: User },
  ],
});
```

> **为什么 history 模式要服务端配置?** 因为刷新 `/user/123` 时,服务器会去找这个路径的文件(404),需要 fallback 规则把它指回 `index.html`,交给前端路由处理。

---

## 二、动态路由与嵌套

```js
// 动态参数 :id
{ path: "/user/:id", component: User }
// 组件内拿参数:useRoute().params.id

// 嵌套路由(带 <router-view>)
{
  path: "/admin",
  component: AdminLayout,
  children: [
    { path: "dashboard", component: Dashboard },
    { path: "users", component: Users },
  ],
}
```

---

## 三、导航守卫

路由跳转前后的"关卡",做登录校验、权限控制:

```js
// 全局前置守卫(最常用)
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isLogin()) {
    return { path: "/login", query: { redirect: to.fullPath } };
  }
});
```

| 类型 | 例子 |
|------|------|
| 全局 | `beforeEach` / `afterEach` |
| 路由级 | `beforeEnter` |
| 组件级 | `beforeRouteEnter` / `beforeRouteLeave` |

> 守卫返回 `false` 取消导航、返回 location 重定向、返回 `true`/`undefined` 放行。

---

## 四、路由懒加载

```js
const User = () => import("./views/User.vue");   // 按需加载 chunk
{ path: "/user/:id", component: User }
```

- 配合打包器**代码分割**,路由被访问时才加载对应 JS
- 首屏只加载当前页 → 更快(呼应 5.3 分包)

---

## 五、小结

```
Vue Router = 路径匹配 + 组件渲染 + 导航管理

模式:history(干净,需服务端 fallback)/ hash(免配置)
动态 :id、嵌套 children(<router-view>)
守卫:beforeEach 全局 / beforeEnter 路由级 / 组件级
懒加载:()=> import() 按需分包
```

## 六、面试题

**Q1:history 和 hash 模式的区别?各有什么优缺点?**

`hash` 用 `#` + `hashchange`,兼容好、**无需服务端配置**,但 URL 有 `#` 不美观、对 SEO 略差;`history` 用 History API,URL 干净、利于 SEO,但**刷新需服务端 fallback** 且要 `popstate/pushState` 支持。现代项目普遍 `history` + Nginx/网关兜底。

**Q2:如何做"未登录跳转登录页,登录后回跳原页"?**

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !store.isLogin) {
    return { path: "/login", query: { redirect: to.fullPath } }; // 记录原路径
  }
});
// 登录页成功后:router.replace(route.query.redirect || "/")
```

**Q3:为什么路由要用"懒加载"?**

路由级 `() => import(...)` 会让每个路由组件成为**独立 chunk**(代码分割),只有访问时才加载,减小**首屏 JS 体积**、加快首屏渲染;不懒加载则所有页面打在一个包里,首屏很重。
