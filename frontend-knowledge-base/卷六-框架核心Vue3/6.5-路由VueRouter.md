# 6.5 路由(Vue Router)

> 卷:卷六 · 框架核心 · Vue3
> 阅读时间:20min

---

## 引言:SPA(Single Page Application,单页应用)的"多页面",靠路由模拟

单页应用只有一个 HTML,靠前端路由**在地址变化时切换组件**。深挖要懂 **history/hash 的底层机制差异**与**导航守卫的解析流程**。

---

## 一、两种路由模式(底层)

| 模式 | URL | 底层机制 | 部署 |
|------|-----|---------|------|
| **history** | `/user/123` | History API(`pushState`/`popstate`) | 需服务端 fallback |
| **hash** | `/#/user/123` | `hashchange` 事件 | 免配置 |

```js
const router = createRouter({
  history: createWebHistory(),   // 或 createWebHashHistory()
  routes: [{ path: "/", component: Home }, { path: "/user/:id", component: User }],
});
```

**为什么 history 要服务端 fallback?** 刷新 `/user/123` 时服务器会去找这个路径的文件(404),需 fallback 规则把它指回 `index.html`,交前端路由。hash 的 `#` 后面不会被发给服务器,所以免配。

---

## 二、动态路由与嵌套

```js
{ path: "/user/:id", component: User }   // useRoute().params.id
{ path: "/admin", component: Layout, children: [
  { path: "dashboard", component: Dashboard },   // 需 <router-view>
] }
```

## 三、导航守卫(解析流程)

```mermaid
flowchart LR
    A[导航触发] --> B[beforeEach 全局守卫]
    B --> C[路由 beforeEnter]
    C --> D[组件 beforeRouteEnter]
    D --> E[确认导航 → 组件切换]
    E --> F[afterEach 后置钩子]
```

```js
router.beforeEach((to, from) => {
  if (to.meta.requiresAuth && !isLogin()) {
    return { path: "/login", query: { redirect: to.fullPath } };  // 重定向
  }
  // 返回 false 取消;undefined/true 放行
});
```

> 守卫是**异步解析的流水线**,返回 false 取消、返回 location 重定向、返回 true/undefined 放行。

## 四、路由懒加载

```js
const User = () => import("./views/User.vue");   // 按需加载 chunk
```

配合打包器**代码分割**,访问才加载,首屏更快(呼应 [5.3](/卷五-构建与工程化/5.3-webpack深入) 分包)。

## 五、小结

```
Vue Router = 路径匹配 + 组件渲染 + 导航管理
模式:history(pushState,需 fallback)/ hash(hashchange,免配)
动态 :id、嵌套 children;守卫流水线(beforeEach→beforeEnter→beforeRouteEnter)
懒加载:()=>import() 按需分包
```

## 六、面试题

**Q1:history 和 hash 模式的区别?优缺点?**

hash 用 `#` + `hashchange`,兼容好、**免服务端配置**,但 URL 有 `#`、SEO 略差;history 用 History API,URL 干净、SEO 好,但**刷新需服务端 fallback**。现代普遍 history + Nginx/网关兜底。

**Q2:如何做"未登录跳登录页,登录后回跳原页"?**

```js
router.beforeEach((to) => {
  if (to.meta.requiresAuth && !store.isLogin) {
    return { path: "/login", query: { redirect: to.fullPath } };
  }
});
// 登录后:router.replace(route.query.redirect || "/")
```

**Q3:为什么路由要用懒加载?**

路由级 `() => import()` 让每个路由组件成**独立 chunk**,访问才加载,减小**首屏 JS 体积**、加快首屏。

**Q4:导航守卫的解析顺序是什么?**

`beforeEach`(全局)→ `beforeEnter`(路由级)→ `beforeRouteEnter`(组件级)→ 确认导航 → `afterEach`(后置,不能改导航)。是**异步流水线**,任一步返回 false/重定向都会中断。

**Q5:为什么 history 模式刷新会 404,hash 不会?**

history 的 `/user/123` 是真实路径,刷新时服务器去找它 → 404;hash 的 `#` 后面**不发送给服务器**,刷新仍只请求 `index.html`,由前端处理。所以 history 需服务端 fallback。

**Q6:`<router-link>` 和 `router.push` 的区别?**

`<router-link>` 是**声明式**(渲染成 `<a>`);`router.push`/`useRouter().push` 是**编程式**(代码里跳转,如提交后跳)。功能等价,场景不同。
